Warm-up 1 — Predict the Console output

Reset the demo, then predict what prints when a 1000 ms timer sits between synchronous statements.

The code

console.log("1. Booking started");
setTimeout(() => {
  console.log("2. Seat verification completed");
}, 1000);
console.log("3. User can continue browsing");

Your prediction (one line per output, in order)

Actual output

Do this in EventPass

  1. Click Reset demo; select A1; choose Callbacks + Successful booking.
  2. Click Book selected seats and watch the timeline.
  3. First trace line: "Synchronous JavaScript finishes; the first timer is pending."

Answer to write

Output order is 1, 3, then 2 about 1 second later. setTimeout only registers the callback; JavaScript keeps running the synchronous statements, and the callback runs after the delay once the call stack is empty (event loop). The page is never blocked.
