Warm-up 3 — Payment decline in Promises mode

Show a payment decline and point to the .catch().

Timeline

The chain being run

checkoutWithPromises(context, hooks)
  .then((ticket) => done(null, ticket))
  .catch((error) => done(error));   // <-- runs when payment rejects

Do this in EventPass

  1. Reset demo → select A1 → Promises → Payment declined → Book.
  2. Verify succeeds, Payment fails, Ticket never starts.
  3. Open js/app.js, line ~230: checkoutWithPromises(snapshot, hooks).then(...).catch((error) => done(error)).

Answer to write

The payment Promise is rejected via reject(error) (inside fromCallback). A rejection skips every following .then(), so the ticket stage never runs, and goes straight to the final .catch((error) => done(error)) in app.js, which shows the failure in the interface.
