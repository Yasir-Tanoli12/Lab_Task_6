Warm-up 2 — Callbacks: success vs seat conflict

Seat A1, Callbacks mode. Compare both runs and find where the paths first differ.

Stages

Verify seatswaiting
Process paymentwaiting
Issue ticketwaiting

Timeline

Do this in EventPass

  1. Reset demo → select A1 → Callbacks → Successful booking → Book. Note all 3 stages complete.
  2. Reset demo → select A1 → Callbacks → Seat conflict → Book. Verify fails; payment and ticket never start.
  3. Open js/flows.js → checkoutWithCallbacks() → the if (verifyError) block.

Answer to write

The paths first differ at the Verify seats stage. In the success run, verifySeatsCallback calls callback(null, {valid:true}), so the code continues to payment. In the conflict run it calls callback(new Error(...)); if (verifyError) is true, so it calls hooks.fail, finished(error) and returns. Payment and ticket are never started.
