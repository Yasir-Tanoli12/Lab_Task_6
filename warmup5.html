Locate the rest and spread operators that update the seat selection.

What just happened

Code (from EventPass js/app.js)

function selectGroup(...ids) {            // REST: collects arguments into array ids
  const additions = ids.filter(id => /* valid, not booked, not selected */);
  selected = [...selected, ...additions].slice(0, 4);   // SPREAD: builds a new array
  render();
}
function autoPickTwo() {
  const choices = /* first 2 available seat IDs */;
  selectGroup(...choices);                // SPREAD in the call: expands array into arguments
}

Do this in EventPass

  1. Reset demo → click Quick-pick two → A1 and A3 get selected (A2 is booked).
  2. Open js/app.js, lines ~135–156: find selectGroup(...ids), [...selected, ...additions] and selectGroup(...choices).

Answer to write

Rest: function selectGroup(...ids) collects the arguments into the array ids. Spread: selectGroup(...choices) expands the array into separate arguments, and selected = [...selected, ...additions] builds a new selection array without mutating the old one.
