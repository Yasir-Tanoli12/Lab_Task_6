Answer to write

The heading is not hard-coded in the HTML. app.js does import { EVENT } from "./data.js" and writes EVENT.title into the DOM when the page loads. Changing the exported constant in the data module and reloading re-runs that code with the new value, so the displayed text updates (one exported value can feed several parts of the page).
