Warm-up 4 — Payment decline in Async / await mode

Identify which awaited stage rejects.

Stages

Verify seatswaiting
Process paymentwaiting
Issue ticketwaiting

Timeline

The function being run

async function checkoutWithAsyncAwait(context, hooks) {
  await tracked("verify",  () => verifySeatsPromise(context), hooks);
  await tracked("payment", () => paymentPromise(context), hooks);   // <-- rejects
  const ticket = await tracked("ticket", () => issueTicketPromise(context), hooks);
  return ticket;
}

Do this in EventPass

  1. Reset demo → select A1 → Async / await → Payment declined → Book.
  2. Verify succeeds, Payment fails, Ticket never starts.
  3. Open js/flows.js → checkoutWithAsyncAwait(). The second await is the one that throws.

Answer to write

The payment stage rejects: await tracked("payment", ...) throws the Error. Execution leaves the async function immediately, so the third line (ticket) never runs. tracked() marks the stage failed and rethrows; the async function returns a rejected Promise, handled by .catch((error) => done(error)) in app.js.
